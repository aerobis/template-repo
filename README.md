1. Update package.json with current details
2. Install with `npm install`
3. Run server with `npm run dev` (auto-reload at localhost:8080)
4. Build server with `npm run build` (outputs to `dist/`)
5. Deploy server with `npm run deploy`

## Files to Customize

- package.json - Update name, description, author, repository URLs
- src/index.js - Application code
- src/template.html - HTML template
